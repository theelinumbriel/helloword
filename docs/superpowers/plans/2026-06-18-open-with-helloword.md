# Open With HelloWord Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user pick a `.md`/`.markdown`/`.txt` file in Finder, choose "Open With → HelloWord", and have the app open with that file loaded for editing (read-only open; Save uses the existing picker).

**Architecture:** `HelloWord.app` becomes an AppleScript applet that handles the macOS open-documents event and shells out to `launch.command` with the file path. `launch.command` (the single launcher) opens the app window at `index.html?open=<encoded abs path>`. `serve.py` gains one read-only endpoint `GET /__open?path=` that returns the file's text. `index.html` reads the `?open=` param on load and feeds the fetched text into the existing `loadText()`.

**Tech Stack:** Python 3 stdlib (`http.server`), bash, AppleScript (`osacompile`), vanilla JS in a single HTML file. Tests: bash + `curl` for the server/launcher, the existing `tests/hw-test.sh` (headless Chrome) for the page, manual Finder e2e for the bundle.

**Reference spec:** `docs/superpowers/specs/2026-06-18-open-with-helloword-design.md`

- [ ] **Step 3: Implement the endpoint in `serve.py`**

Add `import urllib.parse` to the imports block (next to the existing `import os`):

Add this constant just before the `class Handler` line:

ALLOWED_OPEN_EXT = {".md", ".markdown", ".txt"}

Add these two methods inside `class Handler` (e.g. right after `end_headers`):

```python
    def do_GET(self):
        parsed = urllib.parse.urlsplit(self.path)
        if parsed.path == "/__open":
            return self.handle_open(parsed.query)
        return super().do_GET()

    def handle_open(self, query):
        path = (urllib.parse.parse_qs(query).get("path") or [""])[0]
        if os.path.splitext(path)[1].lower() not in ALLOWED_OPEN_EXT:
            self.send_error(403, "Unsupported file type")
            return
        if not os.path.isfile(path):
            self.send_error(404, "File not found")
            return
        try:
            with open(path, "rb") as f:
                data = f.read()
        except OSError:
            self.send_error(404, "Cannot read file")
            return
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)
```

- [ ] **Step 1: Write the applet source**

Create `helloword.applescript`:

```applescript
on run
	launchHelloWord(missing value)
end run

on open theFiles
	repeat with f in theFiles
		launchHelloWord(POSIX path of f)
	end repeat
end open

on launchHelloWord(posixPath)
	-- The bundle lives inside the repo; the repo dir is the bundle's parent.
	-- `dirname` of a path ending in "/" drops the last component, so
	-- dirname ".../md_editor/HelloWord.app/" == ".../md_editor".
	set repoDir to do shell script "dirname " & quoted form of (POSIX path of (path to me))
	set launcher to repoDir & "/launch.command"
	if posixPath is missing value then
		do shell script quoted form of launcher
	else
		do shell script quoted form of launcher & " " & quoted form of posixPath
	end if
end launchHelloWord
```

- [ ] **Step 2: Write the build script**

Create `build-helloword-app.sh`:

```bash
#!/usr/bin/env bash
# Rebuilds HelloWord.app as an AppleScript applet that handles Finder "Open With".
# Re-applies the icon, identifier, and document-type registration on top of osacompile's output.
set -euo pipefail
ROOT="$(cd "$(dirname "$0")" && pwd)"
APP="$ROOT/HelloWord.app"
PB=/usr/libexec/PlistBuddy

# Preserve the existing icon (canonical source: repo root, else the current bundle).
ICON="$ROOT/helloword.icns"
[ -f "$ICON" ] || ICON="$APP/Contents/Resources/helloword.icns"
TMPICON="$(mktemp /tmp/hwicon.XXXXXX).icns"
cp "$ICON" "$TMPICON"

BUILD="$(mktemp -d /tmp/hwapp.XXXXXX)/HelloWord.app"
osacompile -o "$BUILD" "$ROOT/helloword.applescript"

# Icon
cp "$TMPICON" "$BUILD/Contents/Resources/helloword.icns"
PLIST="$BUILD/Contents/Info.plist"
$PB -c "Set :CFBundleName helloword" "$PLIST"
$PB -c "Add :CFBundleDisplayName string helloword" "$PLIST" 2>/dev/null || $PB -c "Set :CFBundleDisplayName helloword" "$PLIST"
$PB -c "Add :CFBundleIdentifier string com.helloword.app" "$PLIST" 2>/dev/null || $PB -c "Set :CFBundleIdentifier com.helloword.app" "$PLIST"
$PB -c "Add :CFBundleIconFile string helloword" "$PLIST" 2>/dev/null || $PB -c "Set :CFBundleIconFile helloword" "$PLIST"
$PB -c "Add :NSHighResolutionCapable bool true" "$PLIST" 2>/dev/null || true
$PB -c "Add :LSMinimumSystemVersion string 10.13" "$PLIST" 2>/dev/null || true

# Document types: .md / .markdown / .txt, role Editor, Alternate rank (appears in "Open With").
$PB -c "Add :CFBundleDocumentTypes array" "$PLIST" 2>/dev/null || true
$PB -c "Add :CFBundleDocumentTypes:0 dict" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeName string 'Text / Markdown Document'" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeRole string Editor" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:LSHandlerRank string Alternate" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeExtensions array" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeExtensions:0 string md" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeExtensions:1 string markdown" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:CFBundleTypeExtensions:2 string txt" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:LSItemContentTypes array" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:LSItemContentTypes:0 string net.daringfireball.markdown" "$PLIST"
$PB -c "Add :CFBundleDocumentTypes:0:LSItemContentTypes:1 string public.plain-text" "$PLIST"

plutil -lint "$PLIST"

# Swap into place
rm -rf "$APP"
mv "$BUILD" "$APP"

# Register with LaunchServices so Finder shows it in "Open With".
LSREG="/System/Library/Frameworks/CoreServices.framework/Versions/A/Frameworks/LaunchServices.framework/Versions/A/Support/lsregister"
[ -x "$LSREG" ] && "$LSREG" -f "$APP"

echo "Built $APP"
```

## Notes for the implementer

- **Read-only by design:** there is intentionally no server write endpoint. Do not add one.
- **`serve.py` only handles GET today.** The new `do_GET` override must call `super().do_GET()` for every non-`/__open` path or static serving breaks.
- **`/__open` `path` is an absolute filesystem path**, URL-encoded by `launch.command`. `parse_qs` decodes it.
- **The applet executable is named `applet`** (osacompile default) with `CFBundleExecutable=applet` — that is expected; the old `Contents/MacOS/helloword` bash script is gone.
- **If Finder doesn't show HelloWord** in "Open With", re-run `build-helloword-app.sh` (it calls `lsregister -f`), or move/rename the app once to nudge LaunchServices.
- **macOS may show a Gatekeeper prompt** the first time the locally-built unsigned app opens via Finder; the user clicks Open once.
